# AtCoder

AtCoder の問題を解いたコードの置き場
主に C++ を使う

## 目標

コードを書く習慣を続けるために、毎日最低 1 問は解く。普段は ABC の A・B 問題が中心

土曜日にバイトがなくて時間がある日は、できるだけ ABC に参加する

PC から離れたい日でも少しはコードに触れておきたい。
GitHub の草を生やし続けるのも続けるためのモチベーションの一つ

## ディレクトリ構成

`contests/` の下にコンテストごとのフォルダを置く。
各フォルダには問題ごとのコードとローカルテスト用のファイルが入っている

```text
contests/
└── abc417/
    ├── contest.acc.json
    └── a/
        ├── main.cpp
        └── tests/
```
